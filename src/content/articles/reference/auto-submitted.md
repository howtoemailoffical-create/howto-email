`Auto-Submitted` indicates whether a message was generated by an automatic process.

Values distinguish ordinary user-generated mail from auto-generated and auto-replied messages.

Automated responders can use this as one signal to avoid replying to another automated system and creating a mail loop.

It should be part of a broader loop-prevention design rather than the only safeguard.

RFC 2142 defines conventional mailbox names for operational roles.

Examples include:

- `abuse@`
- `security@`
- `hostmaster@`
- `webmaster@`
- `postmaster@`

Not every address has the same protocol requirement, but predictable role addresses make it easier to reach the responsible function without knowing a person's name.

Protect them from becoming unmonitored spam sinks.

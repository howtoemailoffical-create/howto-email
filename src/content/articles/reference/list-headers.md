Mailing-list software can expose list operations through standardized headers such as:

- `List-Id`
- `List-Help`
- `List-Subscribe`
- `List-Unsubscribe`
- `List-Post`
- `List-Owner`
- `List-Archive`

These fields make list identity and actions machine-readable instead of forcing clients to scrape message bodies.

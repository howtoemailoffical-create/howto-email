`5.7.1` represents a delivery-not-authorized or message-refused condition.

It can appear in situations involving relay restrictions, sender/recipient policy, filtering or other security controls.

The code is not specific enough to tell you which DNS record to change.

Read the full receiver diagnostic and correlate it with authentication, reputation, content and routing evidence.
